# AmazonSalesDashboard
Overview

This Power BI Sales Dashboard provides an interactive visualization of sales data, enabling better insights into business performance across years, months, products, categories, and payment modes.

The dashboard helps users analyze total sales, profit margins, and key product performance efficiently through dynamic filters and visuals.
Objectives

Monitor overall sales performance and profit trends.

Identify top-performing products and categories.

Analyze sales across different years and months.

Understand how payment modes and sales types (e.g., wholesaler/retailer) impact revenue.
Key Features
🔹 Filters and Slicers

Year Selector: Compare performance between 2021 and 2022.

Month Selector: Analyze monthly sales trends.

Sales Type & Payment Mode: Filter data by customer type (e.g., Wholesaler) and payment mode (e.g., Cash).

🔹 KPI Cards

Total Selling Value – Displays the overall revenue generated.

Profit & Profit % – Highlights profitability metrics.

Top Product KPIs – Showcases best-selling products.

🔹 Visual Components

Bar Chart: Monthly sales and profit comparison.

Line Chart: Daily sales trend visualization.

Donut Charts: Breakdown by Sales Type and Payment Mode.

Category Chart: Sales contribution by category.
How to Use

Download or clone this repository:

git clone https://github.com/ShaikSameer0407/AmazonSalesDashboard.git


Open the .pbix file in Power BI Desktop.

Connect your dataset or update the existing one.

Use slicers (Year, Month, Payment Mode) to explore insights.
Future Enhancements

Integrate real-time data using Power BI Service.

Add regional filters (e.g., by state or city).

Include forecasting trends using Power BI AI visuals.

Publish dashboard to a third-party website or SharePoint for accessibility.
